# Lane prep packs (Bun-style)

Before `domain-increment` build fan-out, each Wave 0 lane needs:

1. **admission.md** — AC, allowlist, HOLDs, verification commands  
2. **OWNERSHIP.tsv** — single-writer facts for the lane  
3. **trial receipt** — 1–3 files green under cargo test  

Templates live next to this README; filled packs are per-increment under worktrees (not necessarily committed until the increment lands).
