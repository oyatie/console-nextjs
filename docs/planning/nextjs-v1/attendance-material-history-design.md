## Contract and activation boundary

Nullable reference plus UNLINKED explicitly expands the current published schema. Previously returned valid matching LINKED records remain equivalent; malformed references previously labeled LINKED intentionally change to null/UNLINKED, but this is not universal backward compatibility: strict old clients may reject newly visible rows. This proposal permits source evolution only in the independent pre-exposure v1 fork, whose existing Next attendance prototype is unbound and excluded from production. It does not modify or activate the concurrently developed Console API. Activation requires clients to support the expanded schema. If existing deployed consumers of this fork require the nonnullable contract, stop and return to review for a versioned raw-history representation; do not hide raw facts to satisfy that old shape. This compatibility decision requires explicit independent design review.
